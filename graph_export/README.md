# Download a populated graph

Download a pre-populated graph in the following formats:

- [yaml](yaml/ai-risk-ontology.yaml)
- [owl](owl/ai-risk-ontology_schema.ttl)
- [cypher](cypher/ai-risk-ontology.cypher), for Neo4j and other openCypher databases
- [sigma.js json](json/ai-risk-ontology-sigma.json), for graph viewers built on sigma.js
