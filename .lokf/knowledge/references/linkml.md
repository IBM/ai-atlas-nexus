# Overview

**LinkML** is the modelling framework underpinning the whole project: the ontology is LinkML YAML, the knowledge graph is LinkML instance data, Pydantic datamodel classes are generated with LinkML tooling, and `linkml`/`linkml_runtime` are core dependencies in `pyproject.toml`.
