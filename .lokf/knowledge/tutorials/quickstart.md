# Overview

The **Quickstart notebook** (`docs/examples/notebooks/AI_Atlas_Nexus_Quickstart.ipynb`) is the entry-point lesson for new users of the library. The same folder holds further example notebooks - risk identification, AI task/domain identification, auto-assist questionnaire, risk categorization, crosswalk generation and taxonomy-mapping evaluation, ARES evaluation, SHACL rule inference, subgraph extraction, and more - which are not yet individually mapped in this bundle (see the [Knowledge Sources Map](../playbooks/knowledge-sources.md)).
